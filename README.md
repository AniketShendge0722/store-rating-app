# Store Rating Management System

A Full Stack Store Rating Application built using:

## Tech Stack
- React.js
- Material UI
- Node.js
- Express.js
- MySQL
- JWT Authentication

## Features
- User Authentication
- Role Based Login
- Admin Dashboard
- Store CRUD Operations
- Ratings System
- User Management
- Protected APIs
- Responsive UI

## Modules
### Admin
- Manage Stores
- Manage Users
- View Ratings

### User
- View Stores
- Give Ratings
- Update Ratings

## Installation

### Frontend
```bash
npm install
npm start
```

### Backend
```bash
npm install
npm run dev
```
